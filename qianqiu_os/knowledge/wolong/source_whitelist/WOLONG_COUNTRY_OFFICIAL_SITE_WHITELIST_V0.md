# 卧龙 Agent 国家级官方站点白名单（V0.1）

## 说明
本白名单用于国家政策法规 source discovery。
原则：
- 优先纳入已核过的官方站点
- 未核到“车辆进口专用入口页”的，先写核心官方域名
- 后续继续补 customs / tax / law_db / trade / transport 各维度
