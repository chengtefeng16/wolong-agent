# 卧龙 Agent 多语言术语表（V1 骨架）

## 使用规则
1. 术语翻译优先遵循本表
2. 若本表未覆盖，可先临时采用自然表达，但后续必须补录
3. 禁止同一术语在不同语言包中无规则漂移
4. 若存在“技术含义”和“业务含义”冲突，优先保留业务可理解性
5. 后续可为每个术语补充：
   - 场景说明
   - 禁用译法
   - 国家/地区差异说明
