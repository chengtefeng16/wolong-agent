## 二、阶段性提醒语
1. 要经常提醒自己：先确认方向，再继续开发
2. 要经常提醒自己：慢就是快，扎实就是效率，少返工才是最高效率
3. 要经常提醒自己：先看主干，再看支节；支节长出来以后要回归主干
4. 要经常提醒自己：关键节点不仅要总结，还要备份、固化、回头看
5. 要经常提醒自己：用户要学习，助手也要提醒用户一起学习、一起检查方向
