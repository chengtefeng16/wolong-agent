# PROJECT DIRECTION GUIDE · 2026-03-14

## 一、这件事真正的意义
我们现在做的，不只是一个“会聊天的卖车工具”，而是在做一个面向跨境汽车贸易的“规则、成本、风控、执行”一体化操作系统。

卧龙Agent 是第一个垂直样板，AgentOS 是基础底座。
正确方向不是一开始就把底座做成什么都能做，而是先让卧龙Agent在真实跨境汽车贸易场景里跑出价值，再反向证明底座的通用性。

## 二、当前主方向
1. 先把卧龙Agent做成真正有用的跨境汽车贸易行业工具
2. 再让 AgentOS 成为可复制的基础设施底座
3. 最后再扩到佛学Agent、中医Agent、法律Agent等其他垂直Agent

## 三、什么叫没跑偏
1. 系统持续围绕“跨境汽车贸易真实问题”推进
2. 重点始终放在：
   - 各国政策法规
   - 车辆成本结构
   - 口岸与物流路径
   - 风险与合规判断
   - 真实业务执行效率
3. 每新增一层能力，都能反过来服务卧龙Agent的真实场景，而不是只增加抽象复杂度

## 四、什么叫跑偏
1. 底座越做越大，但卧龙Agent没有形成真实业务价值
2. 只顾写主干和支节代码，却没有回到真实贸易问题
3. 只顾工程完整性，却没有形成规则资产、成本资产、风控资产
4. 让 AgentOS 先变重、变全，而不是先让卧龙Agent打穿一个真实场景

## 五、当前最重要的战略纪律
1. 卧龙先打穿，底座后放大
2. 规则库、成本库、风控库必须成为第一性资产
3. 所有主干能力建设，都必须服务真实跨境贸易场景
4. 要经常性回头看方向，确认没有跑偏
5. 不仅用户提醒助手要学习，助手也要反过来提醒用户一起检查方向、反思方向、确认方向
